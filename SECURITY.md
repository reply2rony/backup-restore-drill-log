# Security Policy

This is a starter learning template. It is not a security product
and it performs no backup, restore, or network operation.

- Do not put real passwords, tokens, licence keys, personal data,
  or real system names in the drill log.
- Drill on sample or test data only, in an isolated location —
  never over live production data.
- If you find a problem with this template, please open an issue
  describing it without including any real credentials or data.
